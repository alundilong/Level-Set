### Setup Cuda 
+ make sure cuda driver is installed, if not get installed by downloading torch supporting version
> check by running nvidia-smi.exe
> find torch supporting version through https://pytorch.org/get-started/locally/

+ install correct torch, the link above also shows the command to run for installation
> pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu118
